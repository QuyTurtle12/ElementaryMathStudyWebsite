# ElementaryMathStudyWebsite

## Overview

ElementaryMathStudyWebsite is a web application designed to help elementary school students study and practice mathematics. The platform provides interactive features for students, parents, and administrators to manage learning progress, user accounts, and study materials.

## Key Features

- **User Management:** Supports registration, authentication, and role-based access for students, parents, and administrators.
- **Parent-Child Relationship:** Parents can register children, view their progress, and manage their accounts.
- **Progress Tracking:** Tracks student progress across subjects, quizzes, and topics.
- **Quiz and Study Material:** Offers quizzes and study resources tailored to elementary math topics.
- **Order and Subscription:** Allows users to purchase access to subjects and track orders.
- **Role-Based Access:** Different roles (student, parent, admin) have access to specific features and data.

## Technology Stack

- **.NET 9** with **C# 13.0**
- **Razor Pages** for web UI
- **Bootstrap** for responsive design

## How It Works

- **Students** can log in, take quizzes, and view their progress.
- **Parents** can register children, monitor their learning, and view detailed progress reports.
- **Admins** manage users, roles, and study content.

## Intended Users

- **Students:** Elementary school children learning math.
- **Parents:** Guardians who wish to monitor and support their children's learning.
- **HR/Administrators:** Staff who manage users and educational content.
